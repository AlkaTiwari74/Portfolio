Labs & Hands-on Exploration

Security & Networking Laboratory

Bridging the gap between conceptual standards and actual cloud defense mechanisms.

Cloud Security Foundations

IAM, Access Control & Firewalls
SecOps Intro

Cloud resources without proper identity enforcement are vulnerabilities waiting to be exploited. I focus on understanding identity boundaries, traffic inspection, and logging:

Authentication vs Authorization
Verifying credentials (AuthN) vs granting least-privilege permission grants (AuthZ).
AWS Security Groups vs NACLs
Stateful instance-level firewalls compared to stateless subnet-level filter lists.
Network Segmentation
Separating public customer-facing web subnets from sensitive private database layers.
Practice Tool: IAM Simulator & Policies Rule: Zero Trust

Computer Networking Labs

Cisco Packet Tracer Simulations
Lab Practice

Networking is the backbone of all distributed cloud computing. My lab time is dedicated to building topologies, tracing packets, and subnet calculations:

Topology Creation & Switching
Simulating routers, switches, servers, and host PCs inside Cisco Packet Tracer.
CIDR & IPv4 Subnetting
Computing network IDs, broadcast addresses, usable hosts, and /24 down to /28 splits.
DNS Resolution & NAT Routers
Tracking how private IPs translate to public internet gateways during web traffic.
